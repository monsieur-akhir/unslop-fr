# Politique de confidentialité

*English version below.*

Dernière mise à jour : 8 novembre 2026.

`unslop-fr` est composé uniquement de fichiers Markdown : des consignes de rédaction et des listes de référence que Claude lit pour relire un texte.

- **Données lues** : le plugin ne lit que le texte que l'utilisateur donne à relire dans sa conversation avec Claude. Il n'utilise aucun connecteur et n'accède à aucun autre fichier, compte ou service.
- **Données enregistrées** : aucune. Le plugin n'écrit rien sur le disque et ne conserve rien d'une session à l'autre, sauf en mode « édition de fichier », où il modifie le fichier que l'utilisateur lui a désigné.
- **Données envoyées** : aucune. Le plugin ne contient ni code, ni serveur, ni appel réseau. Aucune donnée n'est transmise à l'auteur ni à un tiers.
- **Traitement par Claude** : le texte relu est traité par Claude comme le reste de la conversation, selon les conditions et la politique de confidentialité d'Anthropic, qui ne relèvent pas de ce plugin.

Questions : https://github.com/monsieur-akhir/unslop-fr/issues

# Privacy policy

Last updated: November 8, 2026.

`unslop-fr` consists only of Markdown files: writing instructions and reference lists that Claude reads to review a text.

- **Data read**: the plugin only reads the text the user asks Claude to review in the conversation. It uses no connector and accesses no other file, account or service.
- **Data stored**: none. The plugin writes nothing to disk and keeps nothing between sessions, except in "file editing" mode, where it edits the file the user pointed it to.
- **Data sent**: none. The plugin contains no code, no server and no network call. No data is sent to the author or to any third party.
- **Processing by Claude**: the reviewed text is processed by Claude like the rest of the conversation, under Anthropic's own terms and privacy policy, which this plugin does not govern.

Questions: https://github.com/monsieur-akhir/unslop-fr/issues
